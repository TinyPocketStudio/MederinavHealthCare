Behandlingar

Ändringar syns på webbplatsen inom en minut. Dolda behandlingar syns inte och kan inte bokas, men gamla bokningar finns kvar.

Kampanj

Kampanjen visas på startsidan från startdatum till och med slutdatum. Behandlingar med kampanjpris visas med kampanjpriset på hela webbplatsen under den tiden.

Bild

Liggande bild fungerar bäst. Den beskärs till bildytan på startsidan, så håll det viktigaste i mitten. Bilden sparas direkt när du väljer den.
